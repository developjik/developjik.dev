# 에이전트 툴링 9종을 npm에 공개했습니다

## 개요

에이전트 앱을 만들다 보면 기능 자체보다 주변에서 반복해서 막힙니다. 브라우저 에이전트가 토큰을 얼마나 쓰는지, 스크린리더는 스트리밍 문장을 어떻게 듣는지, 에이전트가 고쳤다는 UI가 진짜 고쳐졌는지, MCP 서버가 새 사양에서도 동작하는지. 이런 지점을 매번 임시 스크립트로 때우는 대신 도구 아홉 개로 정리했고, 전부 npm v0.1.0으로 공개했습니다.

## 9종 한눈에

| 도구 | 하는 일 | 설치 |
| --- | --- | --- |
| [agent-eye](https://github.com/developjik/agent-eye) | 브라우저 에이전트 프로파일러 — 토큰 청구, DOM/ARIA 노이즈, 유휴 churn, false-success 검증 | `npm i @developjik/agent-eye` |
| [agentleak](https://github.com/developjik/agentleak) | 웹의 숨은 AI 전용 지시문·UA 클로킹·공개 vs 에이전트 텍스트 델타 감사 | `npm i @developjik/agentleak` |
| [agent-ui-guard](https://github.com/developjik/agent-ui-guard) | 스트리밍 AI 앱의 UI·툴콜 불변식 E2E (속성기반) | `npm i agent-ui-guard` |
| [mcp-dual](https://github.com/developjik/mcp-dual) | MCP stateless(2026-07-28) 사양 호환 검사기·듀얼-에라 심 프록시·TS 마이그레이션 툴킷 | `npm i mcp-dual` |
| [proofshot](https://github.com/developjik/proofshot) | 에이전트가 쓴 PR용 before/after 스크린샷·픽셀 diff·a11y 증거 | `npm i @developjik/proofshot` |
| [harness-bench](https://github.com/developjik/harness-bench) | 내 저장소에서 실제 과제를 캐내 코딩 하네스(Claude Code·Codex·OpenCode)를 벤치마크 | `npm i @developjik/harness-bench` |
| [streamscope](https://github.com/developjik/streamscope) | AI 스트리밍 UI(SSE·NDJSON·AG-UI·AI SDK) 녹화·재생·장애 주입 | `npm i streamscope` |
| [agent-ball](https://github.com/developjik/agent-ball) | GitHub Issue 기반 멀티에이전트 턴테이킹 오케스트레이터 (human-in-the-loop) | `npm i @developjik/agent-ball` |
| [livesay](https://github.com/developjik/livesay) | 스크린리더가 실제로 듣는 AI UI 감사·교정 (ariaNotify·ARIA live) | `npm i livesay` |

다섯 종이 `@developjik` 스코프인 건 사연이 있습니다. `agentleak`·`proofshot`·`harness-bench`는 이름이 이미 선점돼 있었고, `agent-eye`·`agent-ball`은 npm의 유사명 방지 규칙(`agenteye`·`agent-base`와 혼동)에 걸렸습니다. 스코프로 네이밍을 지키는 쪽을 택했습니다.

## 몇 가지 배경

**proofshot** — 에이전트가 PR을 올리면 "고쳤다"는 텍스트만 남습니다. 변경 전후 스크린샷, 픽셀 diff, 접근성 델타를 증거로 남기는 걸 Storybook 없이, 설정 없이. [정적 데모](https://developjik.github.io/proofshot/)에서 결과물을 바로 볼 수 있습니다.

**streamscope** — 스트리밍 UI의 버그는 재현이 어렵습니다. 한 번 녹화해 두면 같은 스트림을 몇 번이고 재생하고, 끊김·지연·깨진 청크를 주입하면서 Playwright 회귀 테스트로 굳힐 수 있습니다.

**livesay** — AI가 말하는 문장이 스크린리더에서 어떻게 들리는지는 안 보면 모릅니다. ariaNotify()와 ARIA live region이 실제로 무엇을 읽어 주는지 검사하고, [데모](https://developjik.github.io/livesay/)에서 나쁜 예와 좋은 예를 나란히 들어볼 수 있습니다.

**agentleak** — 사이트가 사람과 에이전트에게 다른 문장을 보여 주는지, 숨은 지시문이 있는지 조사합니다. 공개 페이지와 에이전트 뷰의 텍스트 델타를 비교하는 감사 도구입니다.
